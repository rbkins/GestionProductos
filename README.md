# Sistema de Gestión de Productos

Este proyecto es una aplicación web ASP.NET Core MVC para gestionar productos. Permite crear, listar, editar y eliminar productos, así como subir imágenes asociadas a ellos.

## ⚙️ Tecnologías utilizadas

- ASP.NET Core MVC
- Entity Framework Core
- xUnit (para pruebas unitarias)
- SQL Server

## 🧪 Pruebas

El proyecto incluye pruebas unitarias para el controlador `ProductoController`, incluyendo la validación del precio con descuento y la carga de imágenes.

## 📝 Instrucciones

1. Clona este repositorio.
2. Abre la solución en Visual Studio.
3. Ejecuta el proyecto
4. Asegúrate de que la carpeta `wwwroot/images` exista para guardar las imágenes.
